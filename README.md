# 🦉 Riceillion — the nightly flight

A daily Rice University guessing game. Five Rice prompts, 25 seconds each.
The rarer your answer, the higher your owl flies. 500 points reaches the moon.

## Project layout

```
index.html        page structure (sky, owl, cards)
css/style.css     Rice blue night-sky styling
js/questions.js   the question bank  ← edit this
js/game.js        game logic (timer, matching, scoring, daily rotation)
```
